AUTONOMBRADO DE FIREFOX

Solucion del problema de los archivos de portapapeles que no estan nombrados o guardados, lo cual el navegador de FIREFOX autonmbra, y si pegas un archivo extra puede renombrar con el mismo nombre lo cual algunas paginas pueden negar eso o reemplazar el archivo

SOLUCION

1. Instala Violentmonkey como extension
2. Añade un nuevo script apretando "+" de la extension
3. borra el Script actual que tiene por defecto la extension y agrega el nuevo Script que se comparte
4. Activa el Script en Violentmonkey (si ya esta activo ignora este paso)
5. Recarga la pagina y pega el archivo
